# LÖVE2D data-contract audit — 2026-10-15

Runtime source of truth: `data/catalog/manifest.json`, `definitions/*.json`, `recipes/*.json`; JSON Schema and Python validation remain authoritative. `scripts/generate_love_catalog.py` produces `game/love/objects/catalog_generated.lua` for packaged LÖVE. CI fails on drift. Stage 4 `objects.definitions` reads only the generated registry. `core:world_resource` defines gameplay radius, allowed biomes, and placeholder kind; `core:harvestable` defines ticks/drops. Generated code is not a second hand-edited definition source.

**Boundaries, not yet implemented:** `world.biomes` still owns terrain prototype data in Lua; `world.field` procedural biome/feature probabilities and `world.liquids` surface rules are code constants. Their future versioned data catalogs must not silently change generator v1. Stage 4 `objects.world` holds sparse in-memory depletion; `harvesting` command ledger/events and `wallet` temporary counts are not durable. There is no recovery after process death, inventory, crafting, placed-instance UUID registry, or network authority.

**Safe future save proposal:** introduce **new** LÖVE 2D save_version (do not reinterpret old v1 voxel saves). Manifest with immutable seed, generator_version and catalog/gameplay versions; world-local stable ID registry; unique `world_id`, monotonic `world_revision`, player inventory; sparse generated-object state by `worldobj:v1:seed:gx:gy`; separately indexed placed-instance UUIDs; durable applied-command IDs and HarvestCompleted transaction IDs, with atomic inventory+world state checkpoint. Snapshot plus journal, temp write/validation, backup/rollback, and explicit migrators for older formats are mandatory before using `love.filesystem` in production.

**Determinism risk:** never reinterpret existing procedural IDs with changed seed math/placement rules. Preserve generator_version 1 and implementation, or pin its generator and migrate world state with explicit mapping. Chunk meshes and site caches are disposable; delta, inventory, player, ledger, placed IDs are not. Save/network protocol is Stage 6/8 scope, not claimed by this change. Movement water speed 0.55 and immersion 0.5 remain exactly unchanged. Existing studios, PNG, IndexedDB and backups are untouched.
