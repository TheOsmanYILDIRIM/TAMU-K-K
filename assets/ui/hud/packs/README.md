# TAMU HUD texture packs

Yükleme hedefi: bu klasöre **TAMU_HUD_Correct_Split.zip** dosyasını yükleyin. ZIP içinde `portrait.png`, `hotbar.png`, `joystick.png` ve diğer 26 PNG doğrudan kökte bulunmalıdır. İç içe klasör/ZIP kabul edilmez.

Yerleşim ve görünürlük: `../layout.json`. Godot kaynak kodu: `scripts/modular_hud.gd`. PNG yoksa eski kontrol sistemi çalışmaya devam eder. Bu repo yolu harici Android izinleri veya kullanıcı kaydı istemez.
