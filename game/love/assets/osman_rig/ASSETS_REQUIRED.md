# Osman character art (not yet checked into GitHub)

The playable `.love` package supplied in chat contains `clips.json` and 44 pre-rendered PNG sprite strips in this directory. Those binary strips are not present in this Git branch. **Do not merge this branch until the approved atlas PNGs and manifest are copied into this path and a real LÖVE render test passes.**

The original core/plasma code and files remain untouched, and `TAMU_USE_PLASMA=1` switches the renderer back. The `.love` download is the testable preview, not proof of a successful mobile run.
